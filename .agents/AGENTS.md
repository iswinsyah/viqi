# Project Rules & Customizations

Here are the project-specific rules for this workspace:

## Deployment & Repository Rule
* **Auto-Push & Deploy to Hostinger**: Setiap ada perubahan, modifikasi, dan perombakan layout yang selesai dan terverifikasi, langsung commit dan `git push` ke GitHub (branch `main`) agar memicu auto-deploy ke Hostinger (sesuai instruksi USER).
